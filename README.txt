Sursand Connect Super Admin v3.2

- Logo moved to the LEFT side of the saffron header.
- Opening any module hides the module cards, home request popup, menu and password panel so only that module content is visible.
- Module table/form/detail text sizes increased for readability.
- After successful Save/Edit/Approve/Reject, action forms and detail modals close completely, a success toast appears, and the module refreshes.
- Join Community request detail includes "Notify City Connect".
- Notify City Connect can approve a pending Change Maker and publish a welcome banner to Sursand Connect in one confirmed action.
- Published Change Makers also have a Notify City Connect action.
- Existing confirmation dialogs remain above all forms.

BACKEND REQUIRED:
Use Code.gs v10.1 and run the v10.1 setup before using Notify City Connect.
