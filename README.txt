SURSAND CONNECT SUPER ADMIN APP v1

Owner-only app.
- Login uses the existing Super Admin/Admin ID + password configured in Script Properties.
- Full Sursand Connect administration.
- Create staff admins with name, mobile, email, ward, address and initial password.
- Enable/disable staff admin accounts.
- Staff admins cannot create other admins.
- Host this app in a separate private/unguessable GitHub Pages repository or another separate static host.
